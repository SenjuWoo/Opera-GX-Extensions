## Updating

Drag each wanted CRX from `Release/` onto `opera://extensions`. For Aegis, trust the actual localhost address used by your application and reload that page once after changing trust. Later downloads do not need a refresh between files. Trust covers HTTP/HTTPS on all ports; untrusted websites keep the multi-download block.

A package can update an existing installation only when signing identities match. The builder now reports a different installed identity instead of incorrectly promising an in-place update. Preserve an old optional Archive Helper installation and its key/settings until migration succeeds. Its userscript namespace now uses the current public repository owner, so older Tampermonkey installations may also appear separately.

## Diagnostics and remaining runtime coverage

Debug logging is quiet by default. Each changed extension README documents its local toggle and service-worker/content DevTools console. Aegis exposes its toggle in Command center. Companion's `debug_log` writes a rotating log under `%LOCALAPPDATA%/NebulaGrab/Logs/companion.log`. Startup/config records exclude credentials.

Live OpenRouter requests, authenticated Nexus downloads, site-specific media extraction, external yt-dlp/ffmpeg redirect behavior and long-duration browsing were not exercised. Native smoke tests do not guarantee every website's behavior. Local fixes and downloaded release integrity are separate from installing updates into the normal Opera profile.
