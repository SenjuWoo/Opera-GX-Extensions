## Compatibility boundaries

OLED detection cannot prove compatibility with every site's CSS, graphics or custom editor. Artistic colored/translucent gradients and image backgrounds are preserved rather than treated as a known flat backdrop. Regression coverage targets readable text, inherited paint, reversibility and bounded observer work; it is not a claim of universal perfection.

GX Overdrive requires an affirmative clean-state response before discarding a protected tab. Closed shadow roots, cross-origin embedded frames and application state outside DOM controls remain beyond its dirty-form inspection. Nocturne observes existing/open shadow trees and inserted hosts; attaching a shadow root later without any observed subsequent insertion remains outside that detection path.

The Archive userscript requires a current Tampermonkey build supporting redirect controls (build 6180 or newer). Its added `GM_openInTab` grant can require accepting an update permission prompt. Live Tampermonkey execution, authenticated Nexus/OpenRouter requests, live YouTube ad variants, site-specific media extraction and long-duration browsing were not exercised in this pass.

## Updating and diagnostics

Install only the extensions you use. For signed packages, drag the chosen CRX onto `opera://extensions`; extracted ZIPs can also be loaded unpacked in Developer mode. Normal Opera profiles and saved settings were not modified by the isolated tests.

All nine signing identities match the installed IDs observed during this pass's build. Earlier Archive Helper copies from another signing identity may install separately; preserve their settings/key until migration succeeds. Older userscript namespaces may likewise appear separately.

Debug logging is quiet by default. Each extension README documents its toggle and local service-worker/content DevTools console. Companion's `debug_log` writes to `%LOCALAPPDATA%/NebulaGrab/Logs/companion.log`; credentials are excluded. The [plain-text changelog](Release/CHANGELOG-2026.10.13.txt) contains one block per updated component.
